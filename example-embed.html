🤖 How to Embed This Chatbot on Your Website

This page demonstrates how anyone can add your AI chatbot to their website with just a simple script.

📌 Note: Replace https://your-project.vercel.app with your actual Vercel deployment URL after you deploy!

Step 1: Copy This Script

<script>
  window.CHATBOT_API_URL = 'https://your-project.vercel.app';
  window.CHATBOT_TITLE = 'Support Chat'; // Optional
</script>
<script src="https://your-project.vercel.app/chatbot.js" async></script>

Step 2: Paste Before Closing </body> Tag

Open your HTML file and paste the script just before the closing </body> tag.

Step 3: Done! 🎉

✅ A purple chat button will appear in the bottom-right corner
✅ Click it to chat with your AI agent
✅ Works on mobile and desktop
✅ No CSS conflicts with your website

📋 Full Example Page

<!DOCTYPE html>
<html>
<head>
  <title>My Website</title>
</head>
<body>
  <h1>Welcome to My Website</h1>
  <p>This is my website content...</p>

  <!-- Add chatbot widget here -->
  <script>
    window.CHATBOT_API_URL = 'https://your-project.vercel.app';
    window.CHATBOT_TITLE = 'Help & Support';
  </script>
  <script src="https://your-project.vercel.app/chatbot.js" async></script>
</body>
</html>

🎨 Customization Options

Variable Description Required
CHATBOT_API_URL Your Vercel deployment URL ✅ Yes
CHATBOT_TITLE Custom chat window title ❌ No (default: "Chat Assistant")
