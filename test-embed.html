This is a test page

This page simulates embedding the chatbot widget on any website.

Look at the bottom-right corner! You should see a purple chat button.

Click it to open the ChatKit widget.

How to Embed

To embed this widget on any website, add these two lines before closing </body> tag:

<script>
  window.CHATBOT_API_URL = 'http://localhost:8080';
</script>
<script src="http://localhost:8080/chatbot.js" async></script>

Features

  • ✅ No iframe - direct DOM injection
  • ✅ Shadow DOM for CSS isolation
  • ✅ Single 140KB gzipped file
  • ✅ Works on any website
  • ✅ Mobile responsive
  • ✅ Session persistence
